FinTech · Crypto exchange

Overview

AGCX is a regulated, microservices-based crypto exchange for UAE and global markets. Users deposit in AED, buy, sell and hold digital assets, with KYC and a full back office for the operations team.

I work on it as a Full Stack Developer with a backend focus, building the services behind wallets, transactions, fiat on/off-ramp, KYC and security.

  • RoleFull Stack Developer
  • CompanyWrathCode Technology
  • TimelineJun 2026 – Present
  • Live atarabglobal.ae

What I built

  • Services for buy/sell, wallets, deposits, withdrawals, transfers, currency management, referral, KYC and admin.
  • The transaction lifecycle: state handling, validation, provider status tracking and failure recovery.
  • Fiat-to-crypto and crypto-to-fiat flows with Zand Bank and CryptoSwift.
  • PostgreSQL and MongoDB schemas, with Redis caching.
  • gRPC communication between services, following DDD and Clean Architecture.
  • Containerized services deployed with Docker and Kubernetes.

Security & access

An exchange moves real money, so authentication and authorization had to be strict for both users and the back office.

  • PasskeysPasswordless sign-in
  • OAuth 2.0 / OIDCGoogle and Apple sign-in
  • API keysKey management for programmatic access
  • RBAC / ABAC / PBACRole, attribute and policy-based control for sensitive financial operations
